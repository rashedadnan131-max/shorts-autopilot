Privacy Policy

Last updated: October 29, 2026

Shorts Autopilot is a private tool that a single creator uses to upload their own videos to their own YouTube channels. It has no other users.

What the app accesses

With the creator's permission, the app uses the YouTube Data API scope youtube.upload, which lets it upload videos to the creator's channel. It does not read, download, change or delete any other YouTube or Google account data.

What is stored

The sign-in token that Google issues is stored only on the creator's own computer and is used only to upload the creator's videos. No data is sent to any server run by this app, nothing is shared with or sold to third parties, and no analytics or tracking are used.

Google API Services

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the token file on the creator's computer also stops all access.

Contact

Questions about this policy can be raised through the GitHub profile that hosts this page.
